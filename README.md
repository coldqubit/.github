# coldqubit/.github

Organisation-level management for the **coldqubit** GitHub org.

## What lives where

| Branch | Content |
| --- | --- |
| `main` | Org management: the [org profile README](profile/README.md) and, over time, default community health files (issue templates, `SUPPORT.md`, ...) that apply to every coldqubit repository without one of its own. |
| `web` | The <https://coldqubit.org> website, an orphan branch with no shared history, deployed by GitHub Pages in GitHub Actions mode. |

## Conventions

- `profile/README.md` renders on <https://github.com/coldqubit>.
- Files added here (e.g. `CODE_OF_CONDUCT.md`, issue templates under
  `.github/`) become org-wide defaults; per-repo files always win.
- Website changes go to the `web` branch only; see its own README.
