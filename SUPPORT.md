# Support

## Using a project

Questions about using a specific project go to that project's issue tracker, where the
people who maintain it will see them:

- shotgate: [issues](https://github.com/coldqubit/shotgate/issues) ·
  [docs](https://shotgate.coldqubit.org/docs/)

## The home itself

Questions about the org, its standards, the website, or a
[project proposal](https://github.com/coldqubit/.github/issues/new?template=project-proposal.yml)
go to [this repository's issues](https://github.com/coldqubit/.github/issues).

## Private matters

`info@coldqubit.org`. Security reports follow [SECURITY.md](SECURITY.md), never a
public issue.
