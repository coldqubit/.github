Project home & governance

One maintainer today, structured to grow.

coldqubit is an independent, open-source project home for quantum tooling, not a company and not a one-person hobby. It is built so that no decision depends on any one person staying available.

  • →Routine changes land by lazy consensus; substantial or hard-to-reverse changes are written down before they happen, org-scoped ones at the home, project-scoped ones as ADRs in the project.
  • →New projects start as a proposal issue at the home; every project commits to the same shared standards.
  • →Co-maintainers are welcome at every level, including for a single area such as a backend, the Terraform module, or the docs.
